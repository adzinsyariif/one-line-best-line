A [make.fun](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d) entry for the **One Line, Best Line** bounty: a program that writes a single line of text — at most 240 characters, on a free and entertaining theme — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt` (130 characters, one sentence, one line).

## The line

> My smoke alarm and I have an understanding: it screams, I wave a dish towel, and we both pretend the smoke was part of the recipe.
